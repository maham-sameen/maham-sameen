## 🚀 Featured projects

### 🛒 Bazaarly — AI-powered multi-vendor marketplace
Buyers, sellers and tailors on one marketplace, with realtime chat and an AI assistant (**Bazaarly Munshi**) that answers customers on the merchant's behalf when they're offline — pausing for the customer's approval before placing or cancelling any order.

**Stack:** Kotlin · Jetpack Compose · Clean Architecture · Spring Boot microservices · Spring Cloud Gateway · Kafka · Keycloak · Python · LangGraph · Postgres

▶️ [App demo](https://youtu.be/Q6UDjOCDw5c) &nbsp;·&nbsp; ▶️ [AI agent demo](https://youtu.be/EvKhBYJm-so) &nbsp;·&nbsp; 📂 [android](https://github.com/maham-sameen/bazaarly-android) · [server](https://github.com/maham-sameen/bazaarly-server) · [munshi](https://github.com/maham-sameen/bazaarly-munshi)

### 💬 Chatter — realtime chat with voice & video calls
A full messaging app built end-to-end: JWT two-factor auth, 1-to-1 and group chat over WebSockets, online / last-seen presence, push notifications that ring even when the app is closed, and HD voice & video calls.

**Stack:** Kotlin · Jetpack Compose · MVVM · Koin · Room · Ktor (client + server) · MongoDB · WebSockets · Firebase FCM · Stream Video SDK

▶️ [Demo](https://youtu.be/1XUXYZCZqes) &nbsp;·&nbsp; 📂 [android](https://github.com/maham-sameen/Chatter-Android) · [server](https://github.com/maham-sameen/Chatter-Server)

### 📅 Meerkat — Calendly-style scheduling for Android
Publish your real Google Calendar availability, let invitees book a slot, auto-create the Google Meet event, and email every invitee the time converted to **their own** timezone.

**Stack:** Kotlin · Jetpack Compose · Hilt · Room · Retrofit (Google Calendar API) · Firebase Auth / Firestore / Functions · WorkManager

▶️ [Demo](https://youtu.be/Mtl5rLWHrAw) &nbsp;·&nbsp; 📂 [Meerkat](https://github.com/maham-sameen/Meerkat)
